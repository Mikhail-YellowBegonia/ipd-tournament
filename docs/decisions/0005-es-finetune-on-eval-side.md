# 0005 蒸馏后在评测端用进化策略微调
- 状态：采纳

## 背景
Axelrod 库的 EvolvedANN（17 特征、10 维隐层、约 190 参数）用遗传算法训练，以锦标赛平均分为适应度，在 Axelrod 锦标赛中排名靠前。
强化学习难以对"我方历史被读取"这类跨场闭环效应求梯度。

## 决策
流水线最后一步：学生模型蒸馏完成后，在纯 Python 评测环境中用进化策略（CMA-ES 或 OpenAI-ES）微调，适应度为多配比、多种子的锦标赛总分。

## 理由与权衡
- 直接优化考试环境下的真实分数，包括信誉闭环。
- 进化策略效率随参数量下降，要求学生模型保持在数千参数以内。
- 适应度噪声大，需要固定种子组和足够多的对局。

## 后果
学生模型规模受此约束；EvolvedANN、EvolvedLookerUp、EvolvedFSM、PSO Gambler 移植进对手池；EvolvedAttention（依赖 torch，51MB）只作为训练端强对手。
