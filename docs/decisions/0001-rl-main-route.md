# 0001 以强化学习为主路线，手工基线仅作参照尺
- 状态：采纳

## 背景
没有可信的"正确下法"标签；手工统计特征可能丢失深层信息。

## 决策
策略由强化学习端到端训练。保留一个手工基线（对手建模 + 动态规划），只用于对比，不作为产品。

## 理由与权衡
- 奖励即对局得分，无需人类标注。
- 风险：数据有限时端到端不一定优于先验；基线用于暴露训练问题。

## 后果
任何模型版本必须在留出测试池上超过基线才可提交。


## 2026-11-17 补充：教师初始化与“完全 RL”的边界

阶段 1 的纯 REINFORCE 从零训练会陷入“首手背叛”的局部最优（PR #16 的训练记录，待合并）。
为了把 RL 主路线继续下去，允许：

- 用**手工基线**做行为克隆/DAgger 的初始化教师；
- 在 RL 更新中加入在环教师模仿正则；
- 教师只提供动作标签，**不作为最终提交物**。

这里的“RL 主路线”指：最终策略必须由 RL 目标（对局得分）微调，且能作为
九参数、标准库的单一模型执行；不要求训练过程完全没有教师信号。
“纯 RL”只用于描述无教师的对照实验，不能用来描述教师初始化的版本。
任何对外表述都必须区分“纯 RL”与“教师初始化 + RL 微调”。
