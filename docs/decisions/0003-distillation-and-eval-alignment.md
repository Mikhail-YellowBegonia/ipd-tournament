# 0003 教师-学生蒸馏；评测完全对齐考试环境
- 状态：采纳

## 背景
训练期希望模型容量不受限；提交物只能用标准库、单次 ≤ 0.5 秒。

## 决策
- 训练端可用任意库，教师模型不限速度。
- 学生模型用 DAgger 蒸馏（在学生自己访问到的状态上模仿教师），之后强化学习微调。
- 评测端只用标准库，测单次最坏耗时，目标 ≤ 0.1–0.15 秒，使用 5 个固定种子。

## 理由与权衡
只在教师轨迹上模仿会导致误差累积；最坏耗时比平均耗时更能反映超时风险。

## 后果
所有对外报告的性能数字都必须来自评测端。
