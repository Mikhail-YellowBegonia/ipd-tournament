# 0009 尾部优先：规则层先于学习模型

- 日期：2026-11-17
- 状态：采纳
- 关联决策：ADR 0001（RL 主路线）、ADR 0003（教师-学生）、ADR 0004（信誉成本）、
  ADR 0005（ES 微调）、ADR 0007（RL 训练循环）
- 对应 issue：#6（训练）、#8（蒸馏）、#10（留出池）
- 实施计划：[plan 0001](../plans/0001-tail-first.md)

## 背景

阶段 1 的端到端路线（纯 RL、BC/DAgger、RL 微调）在 2026-11-17 暂停：

- 纯 RL 峰值 31.61；BC-only 32–35；DAgger 42.4；RL 微调最佳单模型 5 种子
  45.38，基线 47.79；
- 两模型集成 47.74 vs 47.87，均值几乎打平，但四个 canonical 的 regret 仍为正；
- 诊断：策略不是"不会合作"，而是"不会在正确的时候背叛"；错误的代价不对称，
  一次错误背叛会触发链式报复。

同日的全池诊断（130 个留出策略、完整 8 轮、`hide_prob=0.1`、seed 0）显示：

- 基线每场 **48.36**，池内第 1，0 故障；
- **16 个对手为负**，3 个低于 -50；
- 最差 `ho_basicb_prober` 为 **-138.75**（接近"全合作对 AllD"的 -170 地板）。

机制不是策略容量，而是**对手模型假设错误**：prober 用 B-C-C 试探，只要对手
第 2 手仍合作就永久背叛；它对其他对手合作，因此基线把它的跨场历史当成
"好人"先验，本场全程合作。逐手序列为基线 `bcccc…c` 对 prober `bccbbbb…b`。

一条纯 Python 规则 `guard_open`（对手首手 B → 我第 2 手 B）：

- prober 单场 -138.75 → **+71.00**；
- 全池 130 × 5 seeds，同场克隆对照：**效应 +1.30**（4/5 种子为正，最差 -0.55；
  克隆对照 -0.18）；
- 标准池 23 对手：41.98 → **52.03**（+10.05，主要来自 prober）。

同时发现评测协议噪声：官方"30 个/种子 × 5 种子"下，**同一策略对自身的 gap
可达 ±3**；+1.6 的效应落在噪声内。后续筛选必须用全池 130（或 >=100 对手）
+ 多 seed + 克隆对照。

## 决策

1. **尾部优先**：先把规则层的已知大洞补上，不继续端到端 RL。
2. **规则先于模型**：能用一条可解释、零运行时风险的规则修掉的，不训练模型。
3. **评测协议**：决策用全池 130 × 5 seeds + 同场克隆对照；30 个/种子只做
   快速筛查。
4. **数据纪律**：130 留出池冻结为最终测试；新建 60 个 dev pool 用于迭代；
   规则调参只在 dev + 标准池上做。
5. **门槛**：每条规则必须同时满足全池 mean 不降、worst 不降、标准池不降、
   4 种 `TournamentConfig` 变体不崩。
6. **分类器/q 模型只学残差**：规则修不动的部分，再用 detector 特征 +
   logistic/GBDT 学 q，接回原 DP；带置信度门控，低置信回退基线 q。
7. **基线始终是兜底提交**：任何候选必须在全池上超过基线 +1.0 才替换。

## 理由与权衡

- 规则层的收益/成本比远高于继续 RL：+1.30 的全池效应已经超过阶段 1 RL
  -2.41 gap 的一半，且零训练、零运行时风险、可单测、可解释。
- 规则可单测、可在调试包到位后快速验证；学习模型每增加一个失败面，兜底
  压力更大。
- 代价：规则可能过拟合 130。用 dev pool、config 变体和"机制驱动而非数值
  驱动"的规则设计来缓解。
- 代价：规则的天花板低于端到端模型。但当前数据/时间预算下，先拿确定的
  分数更优；学习模型作为挑战者保留。
