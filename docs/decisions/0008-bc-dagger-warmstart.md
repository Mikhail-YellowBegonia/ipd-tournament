# 0008 BC/DAgger 热启动 + 在环模仿正则

- 日期：2026-11-17
- 状态：采纳（已实施；阶段 1 按 ADR 0007 修订口径通过，训练暂停，阶段 2/3 待续）
- 关联决策：ADR 0001（RL 主路线）、ADR 0003（教师-学生/蒸馏）、ADR 0007（RL 训练循环）
- 对应 issue：#6（阶段 1 训练）

## 背景

ADR 0007 的纯 REINFORCE 从零训练在阶段 1 出现稳定的局部最优：

- 默认超参数 100 赛季评估约 18–22 分/场，基线约 49；
- 调参 + 合作课程 + 合作初始化可以到 31.6，但继续训练会漂移；
- 策略在首手以 0.27 的概率合作，面对 TFT/Grim/STFT 会锁定互相背叛；
- 对 AllC/soft_majority/rand(0.78) 等可剥削对手又过于"公平"，不会收割。

手工基线（ADR 0001 的参照尺）恰好会这些行为，且它是纯 Python、单次决策
约 0.045 ms，可以低成本生成大量教师标签。项目本来就规划教师-学生蒸馏
（ADR 0003、issue #8），因此先用基线做**行为克隆/DAgger 热启动**，再用
RL 微调，是比继续从零探索更可控的路径。

## 决策

1. **教师**：`ipd.agents.baseline.strategy`，不修改、不参与最终推理的评分；
   只用于生成动作标签。
2. **数据**：
   - 先跑 20 个教师赛季（24 对手/轮、8 轮），得到约 9.6 万条状态-动作；
   - DAgger 迭代：用当前学生采样 10–15 个赛季，逐状态向教师问标签，
     聚合后重新训练；2–4 轮。
3. **监督目标**：编码器 + 动作头做交叉熵；可选的背叛类加权与困难样本加权
   作为实验开关，默认关闭（见实验 0008 的失败方向）。
4. **RL 微调**：从 BC/DAgger 检查点 `--resume`，用 ADR 0007 的 REINFORCE +
   价值基线 + 熵正则，并加入**在环模仿正则**
   `λ · CE(π(s), 教师动作(s))`。训练环境 rollout 时同步记录教师动作到
   `MatchTrajectory.labels`，不额外做一次离线标注。
5. **评估口径不变**：候选策略仍与阶段池 + 基线跑完整 8 轮锦标赛；训练时的
   课程/过采样只改训练池，不改评估池（`train_stage(eval_opponents=...)`）。
6. **集成只作为诊断**：两个微调检查点的动作概率加权集成可以把均值推到
   47.74 vs 基线 47.87，但推理要跑两份模型，暂不作为最终形态；后续若要，
   应蒸馏回单模型。

## 理由与权衡

- **样本效率**：教师标签几乎免费，BC 20 赛季约 10 秒；纯 RL 100 赛季仍
  到不了 30。BC/DAgger 直接注入"首手善意、报复、终局收割"等行为。
- **分布偏移**：纯 BC 在教师轨迹上 96.6% 准确，但 25 手复合误差仍让评估
  只有 32–35；DAgger 用学生自己访问的状态补标签，评估提升到 38.6–42.4。
- **稳定性**：BC/DAgger 初始化的策略已经会合作；RL 用低学习率 + 模仿正则
  微调，评估从 38.6 单调升到 45.8，而纯 RL 会在 18–31 附近漂移。
- **教师上限**：BC/DAgger 的 ceiling 接近基线；要"超过基线"，还需要 RL
  在可剥削对手上多做一点。当前单模型 45.38（5 种子）仍低于基线 47.79，
  差距约 2.4。
- **叙事**：这不是把基线当最终产品；基线只做初始化。但确实削弱了"从零
  RL"的纯度，因此保留 `ipd/training/rl_train.py` 的纯 RL 路径作对照，
  并在 ADR 0001 的"RL 主路线"下记录这一偏离。

## 后果

- 新增 `ipd/training/imitation.py`：`BaselineTeacher`、轨迹收集、DAgger 标注、
  BC 训练、CLI（`--seasons/--dagger-iterations/--defect-weight/...`）。
- `ipd/training/env.py`：`MatchTrajectory.labels`、`rollout(labeler=...)`。
- `ipd/training/rl_train.py`：`imitation_coef`/`imitation_defect_weight`/
  `hard_example_weight`、`eval_opponents`、CLI 超参数入口。
- 测试：`tests/test_training_imitation.py` 等，全量 189 项通过。
- 阶段 1 当前最佳：单模型 45.38（5 种子），集成 47.74 vs 基线 47.87；
  逐 canonical 的 regret 仍为正。严格逐项口径未通过；按 ADR 0007 修订后的
  阶梯口径（均值容差 3、逐项 gap ≤15）**阶段 1 通过**（45.38 vs 47.79）。
- **最终形态**：单模型、RL 微调后的策略；教师只做初始化，集成只做诊断。
- 下一步：
  1. 用**逐对手/逐阶段的模仿权重**或 DAgger 蒸馏把 AllD 的 11–14 分差距补上；
  2. 或者接受"均值持平 + 逐对手略差"，修改阶段 1 验收口径（需明确记录）；
  3. 或者保留集成/反射层作为工程兜底；最终提交仍建议蒸馏成单模型（#7/#8）；
  4. 纯 RL 对照与 BC 路线都应写进实验 0008，便于诊断。

## 替代方案

- 继续纯 RL 课程/初始化（已试，峰值 31.6，漂移）。
- 只做 BC 不做 DAgger（32–35，复合误差）。
- 直接用基线提交（留出池 47.94，合法但违背项目目标，作为兜底）。
- 更复杂的序列模型/显式对手模型（容量实验未显示收益，见实验 0008）。
