# 0002 分层历史编码：先线性计数，再非线性
- 状态：采纳

## 背景
历史 1000 符号；规则禁止跨调用缓存，每次调用都要重新编码；纯 Python 推理。

## 决策
历史与本场分开处理：
- 场内：n-gram 计数 × 可学习嵌入表（线性，耗时与词表大小相关，与长度无关）
- 场间：20 个场向量注意力池化，带时间衰减和掩码
- 本场：小 GRU，以历史嵌入为条件
编码器加辅助损失（预测对手动作、对比学习）。

## 理由与权衡
- 逐步 RNN 读 1000 步在纯 Python 下超时。
- 全局计数会丢失场间差异，故分层。
- 辅助损失的标签是模拟器客观事实，不是人类下法先验。

## 后果
嵌入维度初定 16–32，按耗时预算调整。
