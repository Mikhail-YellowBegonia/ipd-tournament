# 加入 L3 读历史对手后的标准联赛
- 关联决策：ADR 0004

## 假设
加入读历史的对手后，终局背叛、无端背叛等模式开始付出信誉代价，相关策略的相对排名下降。

## 设置
- `python -m ipd.sim.run`：23 个标准对手（实验 0001 的 19 个 + 4 个 L3 标准版本），种子 0–4
- 随机池（`--sample 80`）按新配比 L0/L1/L2/L3 = 0.10/0.35/0.30/0.25 采样
- 其余同实验 0001

## 结果（每场平均分，标准联赛）

| 策略 | 0001 | 0002 |
|---|---:|---:|
| gradual | 38.24 | 43.88 |
| tf2t | 38.33 | 43.84 |
| reputation_gate[tft] | — | 39.89 |
| end_defect(k=1)[tft] | 29.06 | 36.46 |
| endgame_preempt[tft] | — | 35.71 |
| tft | 26.74 | 34.61 |
| end_defect(k=3)[tft] | 26.17 | 30.89 |
| all_d | −12.75 | −18.00 |

- 末 1 手背叛相对 TFT 的优势：+2.32 → +1.85；末 3 手：−0.57 → −3.72。
- 随机池（103 个对手）前 3 名：gradual 及 endgame_preempt[gradual]，约 47 分。
- 性能：`profile()` 处理完整 20×25 历史约 0.12 ms，纯 Python，提交物也可使用。
  对手池的 L3 包装器按历史元组对象缓存画像，103 个对手 × 5 种子从 252 秒降到 20 秒。

## 结论与下一步
- 信誉代价已经出现：终局背叛越长，被提前防范的损失越大。末 1 手仍然有利，
  但这只是 4 个标准 L3 的结果，需要按"读历史策略占比"扫描后再下结论。
- AllD 的分数进一步下降，说明 reputation_gate 有效。
- 下一步：多配比评估协议（路线图任务 6），把 L3 占比作为扫描维度。
