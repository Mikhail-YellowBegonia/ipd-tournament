# 手工基线（概率模型 + DP）评估
- 日期：2026-11-16
- 提交（git commit）：`6e59b8a` Add handcrafted baseline: opponent model + DP (issue #3)
- 合并：PR #11（rebase merge；分支提交因 rebase 重写为 main 上的 `6e59b8a`）
- 关联决策：ADR 0001（手工基线仅作参照尺）；对应 issue #3（取代 issue #1）

## 假设
"对手建模 + 动态规划最优应对"的手工基线可以作为所有学习型模型的对标标准：
它的分数接近且不低于池中最好的启发式策略，同时不受训练随机性的影响。

## 设置
- 实现：`ipd/agents/baseline.py`，考试九参数接口 `strategy()`；只用标准库，
  不保存跨调用状态。模型为"上一回合动作对 × 收益阶段"的对手条件合作概率
  （历史 20 场 + 本场，Beta 先验，本场证据权重 3 倍），对剩余回合按 `repay`
  倒推动态规划；首手先善意（历史显示常背叛起手时才防御）。
- 池子（与 `python -m ipd.sim.run --sample 80` 一致）：`canonical()` 23 个标准对手
  + `sample_population(Random(0), 80)` 个随机参数对手 + 基线 = **104 个**。
- `TournamentConfig` 默认值（hide_prob=0.1 按场隐藏、每场后更新历史、赛程随机、
  超时 0.5 s）；种子 0–4；总耗时约 27 s。
- 命令：`python -m ipd.agents.eval_baseline --top 20`
- 补充：仅标准对手的联赛（24 个，命令加 `--sample 0`），便于与实验 0001/0002 对照。

基线 **第 1 名（53.14）**；前 20 名中其余均为 gradual/tf2t/gtft 族的变体，0 故障。

### 基线对标准对手的每场平均分（随机池 / 标准池）

| 对手 | 随机池 | 标准池 |
|---|---:|---:|
| all_c | 118.00 | 116.85 |
| all_d | −45.00 | −45.25 |
| tft | 72.00 | 72.00 |
| gradual | 72.00 | 72.00 |

对 TFT/Gradual 为"24 手相互合作 + 末手背叛"（72 = 24 手合作收益 + 6 分终局诱惑），
对 AllD 是相互背叛（−45 为池中理论下限），对 AllC 则学会剥削。
无历史的首场（直接对局）对 AllC 会保持 24 手合作（72 分），有历史后才开始剥削。

### 单次决策耗时（完整 20×25 历史 × 300 次调用）

| 最坏 | 平均 | 中位数 |
|---:|---:|---:|
| 0.205 ms | 0.045 ms | 0.061 ms |

目标 ≤ 10 ms（issue #3），余量约 50 倍；最坏情况为末回合 + 完整未隐藏历史。

## 结论与下一步
- 基线在随机池与标准池中均排第 1，作为参照尺足够强：后续模型必须在留出测试池
  上超过它（ADR 0001）。它的高分来源是"用历史识别可剥削对手 + 末手背叛"，
  真实考场中读历史对手更多时，信誉成本会抬高这部分收益的上限。
- 实现上有一处对 issue 文本的有意偏离：动作对级先验使用互惠结构先验
  （我方上一手合作→对手 0.8 合作；上一手背叛→0.2），而不是纯 Beta(1,1)。
  纯均匀先验会让早期 DP 在"未观测状态"上系统性低估报复，导致对 TFT/grim
  连锁背叛（直接对局 −8～−50 分）。首手另有"先善意"规则，因为首手没有
  上一手动作对，DP 在 S=−6 下对未知对手过度悲观。两处都写在模块文档里。
